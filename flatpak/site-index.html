WebRoost

Flatpak repository · latest version @VERSION@

Install (and get automatic updates)

Install from this repository once. After that, KDE Discover, GNOME Software and flatpak update keep WebRoost up to date.

flatpak install --user https://samschultzponsys.github.io/webroost/webroost.flatpakref

Or add the repository and install from it:

flatpak remote-add --user --if-not-exists webroost https://samschultzponsys.github.io/webroost/webroost.flatpakrepo
flatpak install --user webroost io.github.samschultzponsys.WebRoost

Bundles (.flatpak files) from version 1.2 onwards also track this repository.
